# Code of Conduct

## 1. Purpose

The FRAME‑online project aims to provide high‑quality, openly accessible documentation for the FRAME methodology.  
We expect all contributors to maintain a respectful, constructive, and professional environment.

## 2. Expected Behavior

- Be respectful and considerate  
- Provide constructive feedback  
- Use inclusive language  
- Focus on technical accuracy and clarity  
- Collaborate in good faith  

## 3. Unacceptable Behavior

- Harassment or discrimination  
- Personal attacks  
- Disruptive or aggressive communication  
- Knowingly providing false or misleading information  

## 4. Reporting Issues

If you experience or witness unacceptable behavior:

- Open a confidential issue, or  
- Contact the maintainers directly via GitHub  

Reports will be handled discreetly and respectfully.

## 5. Enforcement

Maintainers may take appropriate action, including:

- Warnings  
- Temporary or permanent bans from contributions  
- Rejection of PRs or issues  

## 6. Attribution

This Code of Conduct is adapted from the Contributor Covenant.
