# Reference Architectures

FRAME is extended with the activities of the different member states in Europe, within the priority areas of the ITS directive (Directive 2010/40/EU) and with the methodologies and tools that make a modern ITS architecture attractive and appealing for its users.

A reference architecture applies the FRAME methodology to one ITS service or domain: it selects the User Needs and functionality of the FRAME Repository and adds the motivation, organisational, physical and communication views of that service. The reference architectures below are part of the FRAME Architecture Tool (see [FRAME Architecture v5](frame-architecture-5.md)).

| Reference architecture | Scope | Published |
|---|---|---|
| **NAP** – National Access Points | access to travel and traffic data under the delegated regulations of the ITS Directive | in the FRAME Architecture Tool; detailed version by NAPCORE: [NAP Reference Architecture](https://napcore.github.io/Reference-Architectures-website/uml/nap_architecture) ([GitHub](https://github.com/NAPCORE/NAP-Reference-Architecture)) |
| **National Body** | assessment of compliance with the delegated regulations (self-declarations, compliance assessment) | in the FRAME Architecture Tool from 5.2; detailed version by NAPCORE: [NB Reference Architecture](https://napcore.github.io/Reference-Architectures-website/uml/nb_architecture) ([GitHub](https://github.com/NAPCORE/NB-Reference-Architecture)) |
| **eCall** | pan-European in-vehicle emergency call | in the FRAME Architecture Tool |
| **Safe and Secure Truck Parking (SSTP)** | information and reservation services for truck parking areas | in the FRAME Architecture Tool from 5.1.1 |
| **C-ITS** | cooperative ITS services (day-one services) | in the FRAME Architecture Tool from 5.1.1 |

The method behind the NAP reference architecture and the way the views build on each other are described in *Leveraging FRAME Methodology for EU-Wide Harmonization of National Access Points*, Transactions on Transport Sciences 16(3), 2025 ([article](https://www.tots.upol.cz/artkey/tot-202503-0004_leveraging-frame-methodology-for-eu-wide-harmonization-of-national-access-points.php)).
