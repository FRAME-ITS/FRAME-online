# Contribute

FRAME is maintained openly: the model, its history and this website are on GitHub, and everybody can report a problem or propose a change.

## Report a problem or ask a question

Open an issue in [FRAME-ITS/FRAME](https://github.com/FRAME-ITS/FRAME/issues) – for errors in the model, missing User Needs or functions, problems with the tool or the guides. Please name the element or diagram and the release you use. Problems with this website: [FRAME-ITS/FRAME-online](https://github.com/FRAME-ITS/FRAME-online/issues).

Without a GitHub account, write to contact@frame-online.eu.

## How changes are decided

The FRAME Maintainers classify each issue by its impact:

| Level | Kind of change | Decision |
|---|---|---|
| 1–2 | corrections that do not change the content (typos, wrong relationships) | reviewed by two Maintainers, published in a patch release |
| 3 | moderate changes (new or changed elements, guides) | Technical Change Decision Process, minor release |
| 4–5 | changes of the methodology or the meta-model | Technical Change Decision Process (level 5 with a request for comments), major release |

## Propose a change yourself

Changes to the model are prepared as pull requests in FRAME-ITS/FRAME; each pull request shows the changes of the model per view. Changes to this website are pull requests in FRAME-ITS/FRAME-online – each page has an edit link at the top.

## Reference architectures

The detailed NAP and National Body Reference Architectures are maintained by NAPCORE; report problems with them in their repositories ([NAP](https://github.com/NAPCORE/NAP-Reference-Architecture/issues), [NB](https://github.com/NAPCORE/NB-Reference-Architecture/issues)).
